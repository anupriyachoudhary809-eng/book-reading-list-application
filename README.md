
# Book Reading List Application

## Overview
A responsive web application for managing a personal book reading list.

## Features
- Add books with their titles and authors
- Mark books as read or unread
- Delete books from the list
- Track the number of books read
- Save reading list data in browser local storage
- Responsive layout for desktop and mobile

## Technologies
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Add books and manage your reading list.

## Data Storage
Books are saved in the browser's local storage. The list remains available in the same browser unless its stored data is cleared.

## Learning Outcomes
Practice DOM manipulation, event handling, arrays, objects, browser storage, and responsive design.
